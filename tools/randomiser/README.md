# Randomiser

A Chalkbox classroom tool combining three quick randomisation modes:

- **Numbers** — configurable minimum/maximum, multiple draws, optional no-repeat draws and quick ranges.
- **Dice** — D4, D6, D8, D10, D12, D20 and custom-sided dice, with up to 12 dice and automatic totals.
- **Coin** — animated heads/tails flip.

Also includes local result history, sound/mute, light/dark mode, presentation/fullscreen mode, responsive layouts and keyboard shortcuts.

## Keyboard shortcuts

- `Space` — repeat the current action
- `1` — Numbers
- `2` — Dice
- `3` — Coin
- `F` — presentation mode
