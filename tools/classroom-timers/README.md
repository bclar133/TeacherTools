# Classroom Timers

A projector-friendly suite of classroom timing tools for Chalkbox.

## Included modes

- Countdown with 12 visual themes
- Stopwatch with animated physical button press and lap timing
- Digital, analogue, flip and scenic clocks
- Work/rest interval timer
- Classroom focus presets
- Multi-stage lesson schedule

## Countdown themes

Day & Night, Road Racer, Parachute, Ramp Ball, Rocket, Hourglass, Growing Plant, Popcorn, Rollercoaster, Marble Maze, Candle and Space Journey.

Settings such as theme, mute state and dark mode are stored locally in the browser. The tool is designed to run entirely client-side with no account or server required.
